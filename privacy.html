Privacy Policy

India VPS Backup · Updated November 23, 2026

This personal utility backs up its owner's server service configuration to the owner's Google Drive.

Data and purpose

Recovery archives contain server service configuration, certificates and private keys, program files, service definitions, recovery instructions and integrity checksums. These files are used only for the owner's backup and recovery.

Google Drive access

The utility requests the drive.file permission. It creates backup files and folders and reads them to verify uploads. It does not request access to unrelated files in the owner's Drive.

Storage and sharing

Archives are stored in a private directory on the owner's server and in the owner's Google Drive account. Google OAuth credentials are stored in a restricted server configuration file and are excluded from the backup archives. This utility does not publish the archives, sell data, or send archive contents to advertising, analytics, or AI training services. Transfers to Google Drive use HTTPS.

Retention and control

The utility preserves dated backup versions and does not automatically delete historical backups. The owner can delete backup files from the server and Drive, stop the backup timer, or revoke this application's access in Google account settings. Revoking access stops future uploads but does not automatically remove existing backup files.
