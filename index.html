India VPS Backup

A personal utility for backing up the owner's server service configuration to the owner's Google Drive.

The utility runs on the owner's server. It creates dated recovery archives, uploads them through rclone, and verifies the uploaded data. It uses the Google Drive drive.file permission to access files created by this utility.

This utility is for the owner's private use and does not accept third-party registrations.
